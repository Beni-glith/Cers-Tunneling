Buat **satu script Bash all-in-one** untuk VPS Ubuntu yang mengelola:

* **OpenSSH, Dropbear, XRAY (VMESS, VLESS, TROJAN), OpenVPN (SSL/TCP/UDP), BadVPN UDPGW, SSH WebSocket (WS & WSS)**
* Manajemen akun, monitoring, fix menu, backup/restore, limit user, fitur admin, **serta auto backup ke bot Telegram setiap 12 jam**.

Script hanya untuk penggunaan **legal** (administrasi server pribadi/corporate/lab yang sah).

---

### 0️⃣ Target Environment & Standar Script

* OS minimal: **Ubuntu 20.04 / 22.04**, arsitektur **x86_64/amd64**
* Shebang: `#!/usr/bin/env bash`
* Script berbasis fungsi, contoh:

```bash
check_root()
check_os()
install_dependencies()
install_openssh()
install_dropbear()
install_xray()
install_openvpn()
install_badvpn()
install_websocket_services()

show_main_menu()
show_ssh_menu()
show_xray_menu()
show_trojan_menu()
show_backup_menu()
show_maintenance_menu()
show_information_menu()
show_features_menu()

troubleshooting_menu()
logs_menu()
backup_configs()
restore_configs()
auto_backup_setup()

send_backup_to_telegram()
```

* Wajib ada:

  * Cek root, cek OS, cek arsitektur.
  * Error handling sederhana (cek exit code, cetak `[ERROR]` jika gagal).
  * Komentar jelas di blok penting.

### 1️⃣ Port & Layanan Wajib

Gunakan port dan layanan berikut (boleh dibuat variabel di bagian atas script):

* **OpenSSH : 22**
* **Dropbear : 143, 109**
* **DropbearWS : 443, 109**  (WebSocket depan Dropbear)
* **SSH UDP : 1–65535**

  * Implementasi servis “SSH over UDP” (misalnya via UDP forwarder).
  * Sediakan menu untuk mengaktifkan/menonaktifkan serta memilih port/range.
* **OVPN SSL : 443**
* **OVPN TCP : 1194**
* **OVPN UDP : 2200**
* **BadVPN : 7100, 7300**  (badvpn-udpgw minimal di kedua port ini)
* **SSH WS : 80, 8080**
* **SSH WS SSL : 443**

Tambahan XRAY:

* Buat inbound XRAY (VMESS/VLESS/TROJAN) di port yang wajar.
* Semua port ini harus tampil di menu “Info Service Port”.
* Jika firewall aktif (ufw/iptables), script otomatis membuka port-port tersebut (tanpa menonaktifkan firewall total).

### 2️⃣ Komponen Tunneling

**A. OpenSSH**

* Install & aktifkan service di port 22.
* Menu:

  * Tambah user, delete user, renew, trial account.
  * Cek user yang sedang login.
  * Tampilkan list member & list akun expired.

**B. Dropbear + Dropbear WS**

* Jalankan dropbear di port 143 & 109.
* Tambahkan lapisan WebSocket di 443 dan 109 yang forward ke Dropbear.
* Menu mirip SSH: status service, port listening, dll.

**C. XRAY Core (VMESS, VLESS, TROJAN)**

* Install Xray-core.
* `config.json` misal di `/usr/local/etc/xray/config.json`.
* Inbound minimal:

  * VMESS (WS atau TCP)
  * VLESS (WS/TLS sederhana)
  * TROJAN (port khusus)
* Setiap user:

  * VMESS/VLESS → UUID
  * TROJAN → password random
* Menu manajemen akun per protokol (lihat bagian “Menu XRAY”).

**D. OpenVPN**

* Install & setup OpenVPN:

  * OVPN SSL di port 443
  * OVPN TCP di port 1194
  * OVPN UDP di port 2200
* Script:

  * Generate server config.
  * Generate key/cert minimal.
  * Buat file client `.ovpn` sample untuk masing-masing (SSL/TCP/UDP).
* Menu:

  * Start/stop/restart.
  * Tampilkan list client (kalau memungkinkan).
  * Regenerasi client config.

**E. BadVPN UDPGW**

* Install badvpn-udpgw.
* Jalankan instance:

  * Port 7100
  * Port 7300
* Buat systemd service agar auto start.
* Menu:

  * Start/stop/restart.
  * Cek apakah port 7100 & 7300 listening.

**F. SSH WebSocket & WSS**

* Layanan untuk:

  * SSH WS di port **80 & 8080**.
  * SSH WS SSL di port **443**.
* Boleh lewat nginx atau daemon kecil yang forward WS → SSH/Dropbear.
* Tambahkan komentar singkat cara koneksi dari sisi client.

### 🔟 Auto Backup + Kirim ke Bot Telegram (Setiap 12 Jam)

Tambahkan bagian konfigurasi di awal script:

```bash
TELEGRAM_BOT_TOKEN="isi-token-bot-di-sini"
TELEGRAM_CHAT_ID="isi-chat-id-admin-di-sini"
BACKUP_DIR="/var/backups/autotunnel"
BACKUP_FILE_NAME="autotunnel-backup-$(date +%Y%m%d-%H%M).tar.gz"
```

**Fungsi yang wajib ada:**

1. `backup_configs()`

   * Membuat folder backup jika belum ada.
   * Meng-archive **hanya**:

     * File konfigurasi layanan yang relevan.
     * File database/user data (masa aktif, limit, dll).
   * Menyimpan `.tar.gz` ke `$BACKUP_DIR`.

2. `send_backup_to_telegram()`

   * Menggunakan `curl` ke endpoint:
     `https://api.telegram.org/bot${TELEGRAM_BOT_TOKEN}/sendDocument`
   * Mengirim file backup terbaru sebagai **document** ke `$TELEGRAM_CHAT_ID`.
   * Jika `TELEGRAM_BOT_TOKEN` atau `TELEGRAM_CHAT_ID` kosong, tampilkan `[ERROR]` dan jangan kirim.

3. `auto_backup_setup()`

   * Setelah script selesai di-install / pertama kali dijalankan dengan mode “install”, buat **cron job** otomatis:

     * Interval tiap **12 jam sekali**.
     * Contoh entry cron:

       ```text
       0 */12 * * * root /usr/local/bin/auto-tunnel.sh --auto-backup
       ```

   * Mode `--auto-backup` pada script akan:

     * Memanggil `backup_configs`
     * Lalu `send_backup_to_telegram`

   * Tampilkan status apakah cron sudah terpasang & dimana script disimpan.

### 1️⃣3️⃣ Troubleshooting & Logs

`troubleshooting_menu()` minimal:

* Cek status service: ssh/sshd, dropbear, xray, openvpn, badvpn, nginx/ws, dll.
* Cek port (22, 143, 109, 443, 1194, 2200, 7100, 7300, 80, 8080, dsb) dengan `ss`/`netstat`.
* Validasi sederhana config Xray (pakai `jq` jika ada).
* Tampilkan beberapa baris log terakhir: Xray, SSH/auth, OpenVPN.
* Beri rekomendasi singkat (restart, cek firewall, cek config).

`logs_menu()` opsional untuk akses cepat log per service.
